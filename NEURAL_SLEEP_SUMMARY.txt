--------------------------------------------------------------------------------
SLEEP TRIGGERS
--------------------------------------------------------------------------------

Model sleeps when:

1. FATIGUE (high drift)
   drift > drift_threshold
   → Oscillators drifted too far from φ
   → Need homeostatic reset

2. MAX STEPS AWAKE
   steps_since_sleep > max_steps_awake
   → Forced periodic sleep
   → Prevents unbounded drift

3. MANUAL
   model.apply_homeostatic_reset()
   → Explicit sleep command
   → Between epochs, before eval, etc.

Constraints:
  - Won't sleep if steps_since_sleep < min_steps_awake
  - Prevents too-frequent sleeping

--------------------------------------------------------------------------------
PARAMETER TUNING
--------------------------------------------------------------------------------

DRIFT THRESHOLD:

Too low (< 1.0):
  - Sleep too often
  - Interrupts learning
  - No consolidation

Recommended (1.5-2.5):
  - Balanced frequency
  - Consolidation opportunity
  - Natural fatigue

Too high (> 3.0):
  - Sleep rarely
  - Excessive drift
  - Missed windows

Start with 2.0, adjust based on:
  - If sleeping every 100 steps → increase
  - If never sleeping → decrease
  - If no consolidation → try different value

MIN STEPS AWAKE:

Too low (< 100):
  - Can't learn between sleeps
  - Constant resetting

Recommended (500-1000):
  - Enough time to learn
  - Natural rhythm

Too high (> 2000):
  - May miss consolidation
  - Drift accumulates

Rule: ~20% of expected sleep interval

MAX STEPS AWAKE:

Too low (< 1000):
  - Forced sleep too often
  - Wastes consolidation

Recommended (5000-10000):
  - Safety net
  - Prevents unbounded drift

Too high (> 20000):
  - Defeats purpose
  - No upper bound

Rule: 5-10x expected sleep interval
