  Effective: 64 samples per weight update (16 × 4)
  Same training dynamics, less memory!

--------------------------------------------------------------------------------
HOW GRADIENT ACCUMULATION WORKS
--------------------------------------------------------------------------------

Old (OOM):
  1. Load 64 samples → Forward pass → Backward → Update weights
  2. Repeat
  [Too much memory!]

New (Fixed):
  1. Load 16 samples → Forward → Backward (accumulate)
  2. Load 16 samples → Forward → Backward (accumulate)
  3. Load 16 samples → Forward → Backward (accumulate)
  4. Load 16 samples → Forward → Backward (accumulate)
  5. Update weights with accumulated gradients
  6. Repeat
  [Fits in memory!]

Result:
  - Same effective batch size (64)
  - Same training quality
  - 4x less peak memory usage
  - Slightly slower (4x more forward passes per update)
