--------------------------------------------------------------------------------
WHAT IS HOMEOSTATIC DECAY?
--------------------------------------------------------------------------------

In biological neurons:
  - Neurons have a resting potential (-70mV) they return to
  - After firing, there's a refractory period (~1-2ms)
  - Homeostatic plasticity keeps the system stable

In COSF oscillators:
  - Oscillators have a rest frequency (φ = 1.618) they drift toward
  - After strong activation, refractory period prevents rapid re-firing
  - Homeostatic decay pulls frequencies back to φ during training

RESULT: Neural networks that REGULATE themselves like biological systems.

--------------------------------------------------------------------------------
THREE NEW FEATURES
--------------------------------------------------------------------------------

1. HOMEOSTATIC DECAY
   - Oscillators gradually return to φ-harmonic rest state
   - Decay rate: 0.01 (1% per step toward φ)
   - Prevents unbounded frequency drift
   - Natural regularization during training

2. REFRACTORY PERIOD
   - Prevents rapid repeated firing
   - After strong activation, amplitude reduced by 50%
   - Threshold: 0.05 (minimum time between full activations)
   - Mimics biological neural refractory periods

3. HOMEOSTATIC RESET
   - Full system reset to φ state
   - Like neural "sleep" or rest
   - model.apply_homeostatic_reset()
   - Use after training, between eval runs, or when "overexcited"

--------------------------------------------------------------------------------
HOW IT WORKS
--------------------------------------------------------------------------------

During forward pass (training mode):

1. Compute oscillation: y = A·sin(Ω·x + Θ)

2. Apply refractory period (if enabled):
   - Check activation strength
   - If fired too recently (< threshold), reduce amplitude by 50%
   - Track suppressions

3. Apply homeostatic decay (if enabled):
   - Compute: freq_diff = frequencies - φ
   - Decay: frequencies -= decay_rate × freq_diff
   - Clamp to safe range [0.1, 10φ]
   - Track decay amount

4. Return output

Result: Oscillators learn patterns but stay tethered to φ.

During inference (eval mode):
  - Homeostasis disabled by default
  - Full expressivity, no decay
  - Can manually enable if needed

--------------------------------------------------------------------------------
WHEN TO USE HOMEOSTATIC RESET
--------------------------------------------------------------------------------

✓ After training, before inference
  - Removes training artifacts
  - Starts generation from neutral φ state

✓ Between evaluation runs
  - Ensures consistency across runs
  - Resets accumulated state

✓ Periodic during training (end of epoch)
  - Prevents cumulative drift
  - Like "sleep" for the model

✓ When phase velocity too high
  - If max_phase_velocity > 100
  - Model is "overexcited"
  - Reset calms it down

✓ For reproducible generation
  - Reset before each generation run
  - Same starting state → more consistent outputs

--------------------------------------------------------------------------------
INTERPRETING METRICS
--------------------------------------------------------------------------------

HOMEOSTATIC DRIFT:
  0.0 - 0.1:  At rest, oscillators near φ
  0.1 - 0.5:  Mild activation, close to rest
  0.5 - 2.0:  Moderate activation, learning patterns (NORMAL)
  > 2.0:      Strong activation, consider reset

REFRACTORY SUPPRESSIONS:
  0 - 100:    Normal, occasional suppression
  100 - 1000: Frequent, may need adjustment
  > 1000:     Very frequent, threshold too low

AVG DECAY APPLIED:
  ~0.02:      Normal with decay_rate=0.01
  > 0.1:      Strong decay, frequencies far from φ
  < 0.001:    Minimal decay, already near φ
