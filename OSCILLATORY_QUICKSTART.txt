--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

Import error:
  → Make sure you're in COSF-MI/COSF-MI directory
  → Run: python -c "from src.python.cosf_mi.models.cosf_oscillator import *"

CUDA out of memory:
  → Reduce d_model (768 → 512)
  → Reduce n_layers (12 → 8)
  → Reduce batch_size (16 → 8)
  → Use gradient accumulation

Training very slow:
  → Expected! 30% slower than standard
  → sin/cos more expensive than matmul
  → Consider training smaller model first

Coherence not increasing:
  → Lower learning rate (3e-4 → 1e-4)
  → Check for numerical instability
  → Try different initialization

Julia violations increasing:
  → This shouldn't happen (auto-correction)
  → If it does, reduce coupling_constant (φ → φ/2)
  → Or increase julia_bound (1.5 → 2.0)
