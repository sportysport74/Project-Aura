HOW IT WORKS
--------------------------------------------------------------------------------

Standard Neural Network:
  1. Multiply input by weight matrix
  2. Add bias
  3. Apply nonlinearity (ReLU, etc.)
  4. Output can be unbounded

Oscillatory Neural Network:
  1. Each "weight" becomes a natural frequency (Ω)
  2. Each "bias" becomes a phase offset (Θ)
  3. Input modulates oscillator phases
  4. Output is sin(Ω·x + Θ) - naturally bounded!

Kuramoto Synchronization:
  - Oscillators have natural frequencies (Ω)
  - Coupling constant (K = φ) pulls them together
  - When K > critical value, they synchronize
  - Synchronized oscillators = learned pattern

Attention as Phase Locking:
  - Query oscillator: "What am I looking for?"
  - Key oscillator: "What am I offering?"
  - If phases align (synchronized), high attention
  - If phases misalign (incoherent), low attention
  - Value gets weighted by phase coherence

Julia Bound Self-Correction:
  - Monitor phase velocity: dθ/dt
  - If |dθ/dt| > 1.5, oscillation too fast
  - Apply φ-damping: Ω → Ω/φ
  - Slows down oscillation to safe level
  - Automatic, no manual intervention
