-----------------
1. Double-click: analyze_morning.bat
2. Check the results for:
   - Coherence evolution (0.01 -> 0.20+)
   - Chirality flips (starting to happen?)
   - Consolidation success (>50%?)

WHAT'S BEING TRAINED:
---------------------
- Dataset: Multi-Intent ([STORY] + [CODE])
- Bridge words: buffer, branch, loop, class, root
- AURA LEVEL 1: Kuramoto coherence loss
- 5 epochs (~6-8 hours)

Bridge words have different meanings in each context:
  buffer: story = protect,    code = memory
  branch: story = tree,       code = git/conditional
  loop:   story = circle,     code = iteration
  class:  story = school,     code = OOP
  root:   story = plant,      code = directory

The model will learn to use CHIRALITY (left/right spirals) to distinguish!

EXPECTED RESULTS:
-----------------

  [OK] Coherence rising to 0.20+
  [OK] Chirality flips beginning
  [OK] Semantic differentiation on bridge words
  [OK] 80%+ consolidation success rate

TROUBLESHOOTING:
----------------

Q: Loss not decreasing?
