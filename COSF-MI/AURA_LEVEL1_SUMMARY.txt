WHAT IS AURA LEVEL 1?

Adds Kuramoto coherence loss to create a global "pulse" that coordinates
all oscillators. Transforms isolated musicians into a synchronized orchestra.

WHAT WAS ADDED:

1. Kuramoto coherence loss function
   - Measures phase synchronization across all oscillators
   - Returns coherence R (0-1, higher = more sync)
   - Gates coupling by drift (sync when stable, explore when chaotic)

2. Integration into forward pass
   - Model now returns: (logits, task_loss, sync_loss, coherence)
   - Training uses: total_loss = task_loss + sync_loss
   - Progress bar shows coherence in real-time

3. Enhanced warmup for heartbeat formation
   - Epoch 1: min_steps = 45k, max_steps = 50k
   - Prevents early sleep that disrupts pulse formation
   - Allows 45k steps for oscillators to find shared rhythm

4. Updated training script
   - train_with_aura.py uses Kuramoto loss
   - train_aura.bat for easy execution
   - Coherence tracking in progress bar

EXPECTED BEHAVIOR:

Phase 1 (0-45k steps): Exploration
  - Coherence: 0.01 - 0.05 (low, random)
  - Drift: 1.62 -> 1.0 (high, exploring)
  - Gate: 0.0 - 0.4 (weak coupling)

Phase 2 (45k-60k steps): Heartbeat Formation
  - Coherence: 0.05 -> 0.15 (rising)
  - Drift: 1.0 -> 0.5 (stabilizing)
  - Gate: 0.4 -> 0.8 (strengthening)

Phase 3 (60k+ steps): Synchronized Training
  - Coherence: 0.15 -> 0.30+ (strong sync)
  - Drift: 0.5 -> 0.1 (stable)
  - Gate: 0.8 -> 0.99 (nearly full)
