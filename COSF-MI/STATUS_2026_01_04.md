### 2. Critical Issue Discovered 🚨

**The Problem**:

Training run showed **catastrophic memory loss** after sleep:

```
Before sleep:  Loss = 4.0332
After sleep:   Loss = 8.0799  (+100%)
50 steps later: Loss = 7.8363  (NO RECOVERY)
```

**Root Cause Analysis**:

The `reset_to_rest()` function was performing **full amnesia**:

```python
# OLD (destructive)
self.phases.zero_()            # ❌ Destroys learned relationships
self.frequencies.fill_(φ)      # ❌ Snaps all frequencies to φ
self.sync_state.zero_()        # ❌ Loses synchronization
```

**Why It Matters for Chirality**:

In an oscillatory + chirality architecture:
- **Phase offsets** = semantic relationships
- **Chirality orientation** = polarity information (left/right handedness)
- **Frequency deviations** = concept differentiation
- **Zeroing everything** = destroying the geometric semantic manifold

### 3. Solution: Gentle Sleep ✅

**Implementation**:

Modified `reset_to_rest()` with two modes:

#### Gentle Sleep (gentle=True, default)

```python
# Selective decay - preserves structure
self.phase_velocity.zero_()                    # ✅ Reset fatigue
self.frequencies *= 0.5; frequencies += φ*0.5  # ✅ Decay toward φ
self.phases.fmod_(2π)                          # ✅ Normalize, don't zero
# Preserve: chirality, sync_state, learned patterns
```

**What This Preserves**:
- Phase relationships (semantic structure)
- Chirality orientation (polarity)
- Synchronization patterns
- Frequency offsets (concept differentiation)

**What This Resets**:
- Phase velocity (fatigue indicator)
- Homeostatic counters
- Transient suppressions

#### Destructive Sleep (gentle=False)

```python
# Full reset - for debugging only
# Zeros everything (original behavior)
```

**When to use**:
- Never during training
- Only for testing or between unrelated tasks

## Key Insights

### 1. Chirality Makes Sleep Fragile

**Discovery**: Chirality encodes semantic polarity through geometry.

**Implication**: Full reset destroys chirality-concept alignment.

**Example**:
- Word: "expensive"
- Luxury context: RIGHT-handed spiral (positive)
- Burden context: LEFT-handed spiral (negative)
- Full reset: Breaks this learned association

**Solution**: Gentle sleep preserves chirality orientation.

### 2. Phase Relationships Encode Semantics

**Discovery**: Phase offsets between oscillators represent learned relationships.

**Evidence**: Zeroing phases causes 100% loss spike.

**Implication**: Phases are not just "internal state" - they ARE the learned representations.

**Solution**: Gentle sleep normalizes phases (mod 2π) but doesn't zero them.

### 3. Fatigue vs Structure

**Discovery**: Fatigue lives in velocity and drift, not phase offsets.

**Measurement**:
- Phase velocity: Indicates "excitation" level
- Drift: Distance from φ-harmonic rest
- Phase offsets: Semantic structure

**Implication**: Can reset velocity/drift without destroying structure.

**Solution**: Gentle sleep targets fatigue markers specifically.

## What We Learned

### Critical Discoveries

1. **Sleep was performing anesthesia, not rest**
   - Old: Full reset → 100% loss spike
   - New: Gentle decay → minimal disruption

2. **Geometry carries meaning in this architecture**
   - Phase offsets = semantic relationships
   - Chirality = polarity encoding
   - Frequency deviations = concept differentiation

3. **Chirality makes the model more sensitive**
   - More structure to preserve
   - More fragile during reset
   - Requires gentler sleep

4. **Drift threshold was ineffective**
   - Sleep triggered by `max_steps_awake`, not drift
   - Drift = 1.618 at sleep (threshold was 2.0)
   - Need to lower threshold or adjust accumulation

### Design Implications

1. **Always use gentle sleep during training**
2. **Adjust decay_rate based on model stability**
3. **Monitor consolidation metrics closely**
4. **Consider layer-specific decay rates** (future work)
