## Key findings
1. **Two different "coherence" numbers.** The progress-bar `coh` (0.975) is the Kuramoto heartbeat. The epoch-end "Coherence: 0.22" is how sharply attention focuses (average top attention weight, `cosf_oscillator.py:972`), not Kuramoto.
2. **The heartbeat measures the wrong thing.** The Kuramoto loss runs on the fixed phase-offset parameters (`phases`), not on the live per-token phases (`cosf_oscillator.py:1232`). It reached 0.975 by making those biases nearly equal: the "collapsing to single mode" warning in the doc's own troubleshooting section. It's the same for every input, and its effect is tiny (sync loss <= 0.01 vs task loss ~1.7).
3. **Chirality can't flip.** Only `test_chirality.py` and `test_training_ready.py` call `flip_chirality()`.
4. **Sleep currently does almost nothing to the weights.**
   - Before Oct 3, gentle sleep pulled every weight 50% toward phi = 1.618: `frequencies.mul_(1 - decay_rate).add_(rest_frequency * decay_rate)`.
   - That caused the January "drift 1.62 -> 0.12" result. It was weight collapse: the weight spread went 1.618 -> 0.013 after 7 sleeps.
   - The Oct 3 session removed it (transcript `7569bdb7`).
   - All 80 sleeps in this run were timer-forced (every 10k steps). Drift (0.106) never got near the 1.0 threshold.
   - "Consolidation success 88.8%" is mostly noise. It's measured as the loss before sleep minus the lowest loss in the next 50 steps.
5. **The model code was never in git.** The `models/` rule in `.gitignore` also matches `src/python/cosf_mi/models/`, so it isn't on GitHub either. The Oct 1 shadow copy was corrupt. The original was rebuilt from the Oct 3 transcript: `backups/cosf_oscillator_pre_oct3.py` (old phi sleep at line 754).
