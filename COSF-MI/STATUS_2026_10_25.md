# Status 2026-10-25: teacher data for math-in-chat

Follows STATUS_2026_10_11.md.

## Done
- **Repetition fix** (`chat_with_aura.py`): `sample_next()` (repetition penalty 1.3, no repeated 3-grams) and `loop_length()` (stops a reply when a pattern of up to 8 tokens repeats 3x). Multi-turn math stress test: looping replies went from 15/48 to 0/48.
- **Teacher data generator** (`scripts/generate_cosf_distill.py`): Ollama `qwen2.5:32b` at localhost:11434. 60% math, 40% short dialogue without filler.
  - Math is checked in a sandbox: isolated `python -I`, psutil watchdog (5 s, 512 MB), and an import allowlist.
  - Basic math must pass the teacher's own asserts. For angles, oscillators, Kuramoto, complex numbers and Euler steps, the code computes `result` and its printed value replaces `RESULT` in the answer. The teacher got 0 of 16 right doing these in its head; with this, 18 of 20 got through.
  - Random numbers are put in the prompt (the teacher kept reusing 34 and 3/8; duplicates fell from 16% to 5%).
  - The dialogue prompt includes an AURA fact sheet and a no-live-facts rule (it had made up the weather).
  - Every sample is at most 240 tokens, counted exactly as finetune_chat.py encodes it.
  - Tests: `tests/test_distill_sandbox.py` (21 pass).
- **Blending** (`finetune_chat.py --distill`): 30% teacher data, 5% of it held out as "distill val"; the best model is picked on (chat + distill)/2.
- **Math exam** (`experiments/math_eval.py`): 120 Python-generated questions, 6 kinds. **Baseline aura_chat_smart10: 2/120.**
- **fish.bat** follows the data run ("teacher writing data" -> "DATA READY!"), then the fine-tune.

## Running (unattended)
`run_distill_finetune.sh` (detached):
1. Waits for `logs/distill_10k.log` to say "Done." It restarts the generator if the log goes quiet for 15 min.
2. Runs `ollama stop qwen2.5:32b` and waits for VRAM to clear.
3. Runs `finetune_chat.py` on smart_big_10ep with `--distill`, saving to `checkpoints/aura_chat_distill` (log `logs/aura_chat_distill.log`).
4. Runs the math exam, old vs new, writing to `experiments/results/math_eval_summary.txt`.

After a shutdown or reset: double-click **RESUME_DISTILL.bat** (it starts Ollama if needed, then the data run, the chain and fish; everything resumes). A cut-off last line in the data file is dropped automatically.

## Known limits
- A passing sandbox doesn't guarantee the question makes sense: one backwards complex-number question got through with a wrong answer. A forward-only rule was added after that.
- About the first 1,100 samples came from before the hard-topic fix, so they're almost all basic math.
