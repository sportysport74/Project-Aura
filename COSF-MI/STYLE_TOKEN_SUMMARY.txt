THIS IS DATA PREPROCESSING ONLY - NO MODEL CHANGES!

HOW TO USE:

Step 1: Prepare styled data
  python prepare_styled_tinystories.py

Step 2: Train with styled data
  train_styled.bat
  OR
  python train_with_styled_data.py --model-size tiny --epochs 3 --batch-size 8

WHAT HAPPENS:

- Model sees [STORY] at beginning of each story
- Oscillators learn to condition on style token
- Phase relationships encode style information
- Chirality differentiates semantic polarity within stories
